# CalMelo

Google Calendar reminder bot for LINE Messaging API.

## Features

- Google Calendar integration
- LINE Flex Message notification
- Silent mode (skip notification if no events)

## Setup
```bash
uv venv .
```
## Run
```bash
uv run main.py
```
